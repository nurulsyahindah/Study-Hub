
# Project Title & Description
Study Hub is a simple web-based learning management system designed for students to manage their academic resources. 
It allows users to access course notes, past year questions, quizzes, and lecturer information.

The system is built using HTML, CSS, and JavaScript with Bootstrap for responsive design.

# Features Included
- 🔐 Login system (basic validation)
- 🏠 Dashboard with study overview (total courses, notes uploaded, quiz completed)
- 📊 Study progress chart using Chart.js
- 📚 Notes page with course-based notes display
- 🔍 Search and filter notes by course
- 🧠 Quiz system (course-based quiz with questions and score concept)
- 👨‍🏫 Lecturer page with lecturer details
- 🌙 Dark mode toggle feature
- 📱 Responsive design using Bootstrap
